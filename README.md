## 💡 Tips & Tricks

- **Use punctuation wisely:** A comma adds a short breath, a period adds a longer pause, and an exclamation mark adds emphasis. Experiment with these to make the performance more expressive..
- **Start simple:** Choose a short line of lyrics (like “La la la”) to test voices and settings before working on a full song.. This saves time and lets you learn the feel of each control..
- **Layer multiple generations:** Try generating the same lyric with two very different voices (e.g., a deep male voice and a bright female voice), then mix them to create a unique, blended timbre that you cannot get from a single voice..
- **Adjust pitch manually (advanced):** If you click the **“Edit Notes”** button, you can see the generated notes ona piano roll. You can drag notes up or down to change the melody, fix any wrong notes, or even completely rewrite the vocal line. This is a powerful feature for fine‑tuning your perfect performance..
